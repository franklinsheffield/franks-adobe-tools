# Lab Suite 3.0 (private: for Frank's team, do not share)

## What's in it
- **Lab-3.0-Photoshop.zip**: 8 Photoshop plugins (.ccx): Chroma, Depth, Halo, Scanline, Dithers, Decompressor, Paint and Batch Mock Lab.
- **Lab-3.0-AE-Mac.zip / Lab-3.0-AE-Windows.zip**: 7 After Effects / Premiere Pro effects, the Lab Console panel and installers.
- **lab-console-premiere-3.0.0.ccx**: the Lab Console panel for Premiere Pro.

## New in 3.0
- **New panel design.** The effects panel comes first. Hover help can be switched on or off with HELP. The mouse wheel never changes values. The palette is Night Arcade.
- **Lab names** replace "Frank's ... Brew" everywhere. Plugin IDs are unchanged, so saved looks and old projects still work.
- **Button rule.** Effect buttons sit on their own bar, and every group of buttons has the same size and spacing.
- **Colour 3.0** on every pixel tool. **Depth Lab 2.0** adds Smart depth and a Depth layer. Blending is on all plugins.
- **After Effects:** Effect Controls now start with Motion, then Primary, Advanced and Colour. The Lab Console 3.0 matches the 3.0 rules.
- **Premiere Pro:** all 7 effects work in Premiere Pro and Media Encoder, and there is a Lab Console for Premiere.
- **Paint Lab 3.0.2:** the three white-edged watercolour looks are removed.

## Install
- **Photoshop:** unzip, then double-click each .ccx. Creative Cloud installs it. Restart Photoshop, then open it from the Plugins menu.
- **After Effects / Premiere (Mac):** unzip, quit After Effects, then run `install-mac.command`. It asks for your Mac password. Then run `install-console-mac.command`.
- **After Effects / Premiere (Windows):** unzip, then run `install-win.bat` as administrator. Then run `install-console-win.bat`.
- **Premiere panel:** double-click `lab-console-premiere-3.0.0.ccx`.
