# Mobglow

Neon, bloom and halo glow over the untouched original. (UXP panel, Photoshop 24.4+.)

Install: double-click `dist/mobglow-1.0.0.ccx`, then open Plugins > Mobglow.

1. Pick a preset in Library (Neon Sign, Soft Dream, Club Laser, Vapor Pink, Toxic Green, Ice Halo, Golden Hour, Hologram).
2. Pick the Glow source (highlights, edges or both), the Tint, three Halo sizes and the Finish (fringe, grain, background darken). The pinned preview updates as you go.
3. Apply to document. A new group "Mobglow - <preset>" sits above your image: Glow (Screen), optional Fringe (Lighten) and Background darken. The source stays visible. One Cmd+Z undoes it.

Save your own looks under Library and use Export all / Import to share them with the team.
