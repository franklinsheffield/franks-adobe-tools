# Frank's Chrometone Brew 1.1

Liquid chrome, retro chrome type, 3D extrusion, glow and shine for Photoshop (UXP panel, Photoshop 24.4+).

Install: double-click `dist/chrometone-1.1.0.ccx`, then open Plugins > Frank's Chrometone Brew.

1. Pick a look in Library: 8 Classic (Chrome / Colour) or 16 Retro chrome looks (Glacier Rim, Sunset Slab, Lilac Storm, Dreamy Pearl, Midnight Edge, Heavy Metal, Arcade Gold, Frostbite, Hot Rod Candy, Vapor Mint, Ultra Blue, Rose Ingot, Night Drive, Mercury Drop, Prism Foil, Titan Block).
2. Surface: Auto uses the outline when the layer has transparency or sits on black (bevel width, Chamfer / Round / Rim + flat, Gradient or Horizon reflection with sky and ground colours); Brightness is the classic 1.0 look.
3. 3D Extrusion: depth, angle, perspective, side colours, side shading, edge lines, long shadow.
4. Glow: up to 4 stacked modules (Dreamy, Halo, Neon edge, Inner, Bloom). Shine FX: star glints, sweep streak, rim light, electric arcs.
5. Apply to document. The group "Frank's Chrometone Brew - <look>" holds, bottom to top: Glow (Screen), Long shadow (Multiply), Extrusion, Chrome colour, Chrome shine (Screen), Sparkle (Screen); layers for effects that are off are skipped. One Cmd+Z undoes it.

Use Source "Active layer" for type and logos: the read area widens past the layer so glow and extrusion aren't cut off (inside the document).
Saved 1.0 looks load unchanged: every 1.1 setting defaults to off.
