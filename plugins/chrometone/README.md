# Chrometone

Liquid chrome, metal and holo-foil looks for Photoshop (UXP panel, Photoshop 24.4+).

Install: double-click `dist/chrometone-1.0.0.ccx`, then open Plugins > Chrometone.

1. Pick a preset in Library (Liquid Silver, Polished Gold, Gunmetal, Black Mirror, Holo Foil, Rose Chrome, Y2K Ice, Copper Wire).
2. Adjust Look (gradient stops), Tone, Bands, Relief and Finish. The pinned preview updates as you go.
3. Apply to document. A new group "Chrometone - <preset>" holds a Colour layer and a Shine layer (Screen). One Cmd+Z undoes it.

Save your own looks under Library and use Export all / Import to share them with the team.
