# Frank's Decompressor Brew

Real JPEG damage, chroma smear, bit crush, datamosh and glitch slices. (UXP panel, Photoshop 24.4+.)

Install: double-click `dist/decompressor-1.0.0.ccx`, then open Plugins > Frank's Decompressor Brew.

1. Pick a preset in Library (Crunchy JPEG, Deep Fried, Old Webcam, Datamosh Drift, VHS Rip, 8-bit Crush, Broken Stream, Fax Machine).
2. Set JPEG quality and generations, chroma subsampling, bit depth, then Datamosh and Glitch slices. Change the seed for a new variation. The pinned preview updates as you go.
3. Apply to document. A new group "Frank's Decompressor Brew - <preset>" holds one Decompressed layer. One Cmd+Z undoes it. Many generations on a big image take a while; the panel warns first.

Save your own looks under Library and use Export all / Import to share them with the team.
