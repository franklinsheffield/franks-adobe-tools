# Frank's Worlds Brew: bundled 3D assets

## Fantasy pack
Models by **Kenney** (https://kenney.nl), from the Starter Kit City Builder, 3D Platformer, Basic Scene (Mini Arena) and Racing kits
(https://github.com/KenneyNL). Licence: **Creative Commons Zero (CC0 1.0)**, public domain: free for personal and commercial use,
no attribution required (credit given here as thanks). Converted to Worlds Brew meshes with colours baked per triangle by
`tools/worlds-packs.js`.

## Alien pack
Original models built in code for Frank's Worlds Brew (`js/alienkit.js`). No third-party content.
