# Frank's CRT Phaser Brew

The image on an old tube: scanlines, phosphor mask, convergence, bloom, curvature. (UXP panel, Photoshop 24.4+.)

Install: double-click `dist/crt-phaser-1.0.0.ccx`, then open Plugins > Frank's CRT Phaser Brew.

1. Pick a preset in Library (Arcade Cabinet, Trinitron, Consumer TV, Green Phosphor, Amber Terminal, Broadcast Monitor, Busted VHS Set, Clean Scanlines).
2. Set Screen lines, Convergence, Phosphor mask, Scanlines, Tube (bloom, curvature, corners, vignette), Signal (noise, roll band) and Finish (incl. mono phosphor colour). The pinned preview updates as you go.
3. Apply to document. A new group "Frank's CRT Phaser Brew - <preset>" holds a Screen layer, plus a Scanlines layer (Multiply) if you pick split layers. One Cmd+Z undoes it.

Save your own looks under Library and use Export all / Import to share them with the team.
