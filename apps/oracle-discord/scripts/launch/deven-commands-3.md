**🗺️ Pixel Scape** (its own app, which shares the server with the Oracle)

• `/terrain place:` builds real 3D terrain of any place name or lat,lon, as a rendered image and/or a .glb model. Options: `size` (1 to 40 km), `view` (oblique or top-down), `format` and `relief` (1 to 4×).
• `/model find | random | show` searches my free 3D model library by category, style or vibe, and `show` gives the preview, licence and download.
